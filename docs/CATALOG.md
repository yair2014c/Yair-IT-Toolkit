# App Catalog (curated)

This is a short sample of the catalog; the full curated catalog is listed inside `Windows-Utility-Tool/YairUtility.ps1`.

Examples
- Browsers: Google Chrome, Mozilla Firefox, Microsoft Edge, Brave, Vivaldi
- Security: Malwarebytes, VeraCrypt, Bitwarden, KeePassXC
- Dev: VS Code, Git, Python, Node.js
- Productivity: Microsoft Office (via winget), LibreOffice
