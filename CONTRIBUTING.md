# Contributing

Thanks for your interest in contributing! Small, focused contributions are welcome.

How to contribute
1. Fork the repository and create a feature branch.  
2. Make your changes that are scoped and well-documented.  
3. Open a Pull Request describing the change, why it’s needed, and any testing performed.

Guidelines
- Keep changes focused (one logical change per PR).  
- For code changes, include short testing notes and a brief description of the manual steps required to validate.  
- Be mindful that many scripts require Administrator privileges — avoid landing destructive changes without Simulation Mode support and clear user prompts.

Issue reports
- Provide steps to reproduce, platform details (Windows version, PowerShell version), and relevant script names.
